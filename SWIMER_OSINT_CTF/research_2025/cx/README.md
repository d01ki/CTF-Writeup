世界一着陸が難しい空港「香港アプローチ・カーブ」

長年香港の玄関口として稼働していたカイタック空港は、市街地にあり、過密空港であることから着陸失敗事故や、タッチアンドゴーが多く「世界一着陸が難しい空港」としてパイロットの高い技量が必要であるとされ、また当時、着陸誘導灯は、空港とは無関係の一般ビルの屋上に設置されるなど空港の造りも特殊な国際空港でした。
